Need a hint?Open setup guide

Install with sudo apt-get install -y nginx.

Write the config: sudo tee /etc/nginx/sites-available/rcw-app <<'EOF' … EOF.

Enable it: sudo ln -s /etc/nginx/sites-available/rcw-app /etc/nginx/sites-enabled/.

Test it: sudo nginx -t, then reload: sudo systemctl reload nginx.

Verify: curl -s http://localhost/ and curl -s http://localhost/api/health.

Type help to see all supported commands.
