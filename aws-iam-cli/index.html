What you will practise

  1. List users — List users with aws iam list-users. 25 pts
  2. Create user — Create with aws iam create-user. 25 pts
  3. List policies — List with aws iam list-policies. 25 pts
  4. Attach policy — Attach with aws iam attach-user-policy. 25 pts

Commands used in this lab

  • aws iam list-users
  • aws iam create-user --user-name anna
  • aws iam list-policies
  • aws iam attach-user-policy --user-name anna --policy-arn arn:aws:iam::aws:policy/AmazonS3ReadOnlyAccess
