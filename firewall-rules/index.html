What you will practise

  1. List rules — Show active services with --list-all. 25 pts
  2. Add service — Allow http with --add-service=http. 25 pts
  3. Add port — Open port 8080 with --add-port. 25 pts
  4. Reload — Apply changes with --reload. 25 pts

Commands used in this lab

  • firewall-cmd --list-all
  • firewall-cmd --add-service=http --permanent
  • firewall-cmd --add-port=8080/tcp --permanent
  • firewall-cmd --reload
