SSH Key-based Authentication

Create a modern key pair for the administrator, install it on serverb, and prove that password authentication is unnecessary.

Task 57 of 62 in the RHCSA practice series. Mapped to the published EX200 skill areas.

  • RHCSA / EX200level

Start the interactive lab ↓ Free · runs in your browser · no login

What you will practise

  1. Assess the starting state — Existing key state inspected. 20 pts
  2. Establish verified key-only SSH access — Produce the required modeled system state using supported administrative commands. 60 pts
  3. Validate the resulting state — Passwordless key authentication validated. 20 pts

Commands used in this lab

  • test -e /home/admin/.ssh/id_ed25519
  • ssh-keygen -t ed25519 -N '' -f /home/admin/.ssh/id_ed25519
  • ssh-copy-id -i /home/admin/.ssh/id_ed25519.pub admin@serverb.lab
  • ssh -o PasswordAuthentication=no admin@serverb.lab 'id -un'
