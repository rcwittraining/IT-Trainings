What you will practise

  1. Assess the starting state — Autofs package state inspected. 20 pts
  2. Configure and activate the autofs map — Produce the required modeled system state using supported administrative commands. 60 pts

Commands used in this lab

  • rpm -q autofs
  • printf '/projects /etc/auto.projects\n' > /etc/auto.master.d/projects.autofs
  • printf 'alpha -rw,sync files.lab.example:/exports/alpha\n' > /etc/auto.projects
  • systemctl enable --now autofs
  • ls /projects/alpha && mount | grep '/projects/alpha'
