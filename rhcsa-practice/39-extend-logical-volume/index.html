Extend an Existing Logical Volume

Increase the nearly full XFS application volume by 2 GiB and grow its file system online in one controlled operation.

Task 39 of 62 in the RHCSA practice series. Mapped to the published EX200 skill areas.

  • RHCSA / EX200level
  • 3objectives
  • 10 mintarget time
  • 100points + certificate

Start the interactive lab ↓ Free · runs in your browser · no login

What you will practise

  1. Assess the starting state — Logical volume and file-system capacity inspected. 20 pts
  2. Extend the LV and its file system — Produce the required modeled system state using supported administrative commands. 60 pts
  3. Validate the resulting state — Extended capacity validated. 20 pts

Commands used in this lab

  • lvs /dev/vgapp/lvdata -o lv_size && df -hT /data
  • lvextend -r -L +2G /dev/vgapp/lvdata
  • lvs /dev/vgapp/lvdata -o lv_size --noheadings && df -hT /data
