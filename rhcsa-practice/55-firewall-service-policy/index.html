What you will practise

  1. Assess the starting state — Current public-zone policy inspected. 20 pts
  2. Configure persistent application firewall policy — Produce the required modeled system state using supported administrative commands. 60 pts
  3. Validate the resulting state — Runtime firewall policy validated. 20 pts

Commands used in this lab

  • firewall-cmd --zone=public --list-all
  • firewall-cmd --permanent --zone=public --add-port=8443/tcp
  • firewall-cmd --permanent --zone=public --add-rich-rule='rule family=ipv4 source address=10.24.8.0/24 port port=9443 protocol=tcp accept'
  • firewall-cmd --reload
  • firewall-cmd --zone=public --query-port=8443/tcp && firewall-cmd --zone=public --list-rich-rules
