What you will practise

  1. Assess the starting state — Existing RPM repositories inspected. 20 pts
  2. Configure the approved RPM repository — Produce the required modeled system state using supported administrative commands. 60 pts
  3. Validate the resulting state — Enabled repository validated. 20 pts

Commands used in this lab

  • dnf repolist --enabled | grep training-tools
