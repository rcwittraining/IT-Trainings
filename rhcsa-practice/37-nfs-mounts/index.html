What you will practise

  1. Assess the starting state — Available NFS exports inspected. 20 pts
  2. Create an active and persistent NFS mount — Produce the required modeled system state using supported administrative commands. 60 pts
  3. Validate the resulting state — NFS mount validated. 20 pts

Commands used in this lab

  • showmount -e files.lab.example
  • mkdir -p /engineering
  • printf 'files.lab.example:/exports/engineering /engineering nfs4 defaults,_netdev 0 0\n' >> /etc/fstab
  • mount /engineering
  • findmnt -no SOURCE,FSTYPE /engineering
