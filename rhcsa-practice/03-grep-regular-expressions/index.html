What you will practise

  1. Assess the starting state — Extended regular expression tested. 20 pts
  2. Filter actionable events with regular expressions — Produce the required modeled system state using supported administrative commands. 60 pts
  3. Validate the resulting state — Filtered report validated. 20 pts

Commands used in this lab

  • grep -En '^(ERROR|WARN)[[:space:]]+[0-9]{4}-[0-9]{2}-[0-9]{2}' /var/log/orders.log
  • grep -Ev 'healthcheck|127\.0\.0\.1' /var/log/orders.log > /var/tmp/orders-actionable.log
  • grep -Eq '^(ERROR|WARN)' /var/tmp/orders-actionable.log
