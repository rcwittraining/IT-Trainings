SELinux Port Labels

Allow the web service domain to bind the approved nonstandard TLS port by adding a persistent SELinux port mapping.

What you will practise

  1. Assess the starting state — Existing HTTP port labels inspected. 20 pts
  2. Configure the nonstandard SELinux port label — Produce the required modeled system state using supported administrative commands. 60 pts
  3. Validate the resulting state — SELinux port mapping validated. 20 pts

Commands used in this lab

  • semanage port -l | grep '^http_port_t'
  • semanage port -a -t http_port_t -p tcp 9443
  • semanage port -l | grep '^http_port_t' | grep 9443
