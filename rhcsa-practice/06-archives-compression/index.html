Archive and Compression Operations

Package application configuration with gzip, inspect a bzip2 reference archive, and restore it into an isolated validation directory.

Task 6 of 62 in the RHCSA practice series. Mapped to the published EX200 skill areas.

  • RHCSA / EX200level
  • 3objectives
  • 10 mintarget time
  • 100points + certificate

Start the interactive lab ↓ Free · runs in your browser · no login

What you will practise

  1. Assess the starting state — Archive source size inspected. 20 pts
  2. Create, inspect and restore compressed archives — Produce the required modeled system state using supported administrative commands. 60 pts
  3. Validate the resulting state — Created archive validated. 20 pts

Commands used in this lab

  • du -sh /srv/app
  • tar -czf /backup/app-etc.tar.gz -C /srv/app etc
  • tar -tjf /backup/reference.tar.bz2
  • mkdir -p /restore/reference && tar -xjf /backup/reference.tar.bz2 -C /restore/reference
  • tar -tzf /backup/app-etc.tar.gz | grep -q '^etc/'
