Default File Permissions

Apply a restrictive default umask for operations users and create a shared directory that preserves its group on new content.

Task 56 of 62 in the RHCSA practice series. Mapped to the published EX200 skill areas.

What you will practise

  1. Assess the starting state — Current login umask inspected. 20 pts
  2. Configure secure default permissions — Produce the required modeled system state using supported administrative commands. 60 pts
  3. Validate the resulting state — Default and shared-directory permissions validated. 20 pts

Commands used in this lab

  • su - opslead -c 'umask'
  • printf 'umask 027\n' > /etc/profile.d/operations-umask.sh
  • install -d -o root -g operations -m 2770 /srv/operations
  • su - opslead -c 'umask' && stat -c '%G %a' /srv/operations
