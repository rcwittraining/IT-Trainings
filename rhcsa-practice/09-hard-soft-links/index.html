Hard and Symbolic Links

Provide a same-filesystem recovery name for a policy file and a stable symbolic path for the current application release.

Task 9 of 62 in the RHCSA practice series. Mapped to the published EX200 skill areas.

  • RHCSA / EX200level
  • 3objectives
  • 10 mintarget time
  • 100points + certificate

Start the interactive lab ↓ Free · runs in your browser · no login

What you will practise

  1. Assess the starting state — Source inode inspected. 20 pts
  2. Create hard and symbolic links — Produce the required modeled system state using supported administrative commands. 60 pts
  3. Validate the resulting state — Both link types validated. 20 pts

Commands used in this lab

  • stat -c '%i %n' /srv/policy/current.conf
  • ln /srv/policy/current.conf /srv/policy/current.conf.recovery
  • ln -s /srv/releases/app-4.2 /opt/app-current
  • test /srv/policy/current.conf -ef /srv/policy/current.conf.recovery && test -L /opt/app-current
