Persistent Mounts by UUID or Label

Configure the existing XFS data volume to mount at boot using its UUID rather than a device name.

Task 34 of 62 in the RHCSA practice series. Mapped to the published EX200 skill areas.

What you will practise

  1. Assess the starting state — File-system UUID discovered. 20 pts
  2. Create a persistent identifier-based mount — Produce the required modeled system state using supported administrative commands. 60 pts
  3. Validate the resulting state — Mounted file system validated. 20 pts

Commands used in this lab

  • blkid /dev/vgapp/lvdata
  • mkdir -p /data
  • printf 'UUID=7b5d-rcw-2026 /data xfs defaults 0 0\n' >> /etc/fstab
  • mount -a
  • findmnt -no SOURCE,FSTYPE,TARGET /data
