Software Installation and Updates

Install one approved local RPM, update managed packages from configured remote sources, and review the resulting transaction.

What you will practise

  1. Assess the starting state — Enabled software sources inspected. 20 pts
  2. Install and update from approved sources — Produce the required modeled system state using supported administrative commands. 60 pts
  3. Validate the resulting state — Latest software transaction validated. 20 pts

Commands used in this lab

  • dnf repolist --enabled
  • dnf install -y /var/tmp/rcw-agent-2.1-1.el10.x86_64.rpm
  • dnf update -y
  • dnf history info last
