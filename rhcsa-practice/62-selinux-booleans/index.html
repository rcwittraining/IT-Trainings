Persistent SELinux Booleans

Permit the web service to make required outbound network connections using the narrow policy Boolean and persist the change.

Task 62 of 62 in the RHCSA practice series. Mapped to the published EX200 skill areas.

What you will practise

  1. Assess the starting state — Current SELinux Boolean inspected. 20 pts
  2. Enable and persist the required SELinux Boolean — Produce the required modeled system state using supported administrative commands. 60 pts
  3. Validate the resulting state — Persistent Boolean state validated. 20 pts

Commands used in this lab

  • getsebool httpd_can_network_connect
  • setsebool -P httpd_can_network_connect on
  • getsebool httpd_can_network_connect | grep -- '--> on'
