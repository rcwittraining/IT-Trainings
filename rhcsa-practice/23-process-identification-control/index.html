Process Identification and Control

Identify the process consuming the most CPU, terminate the confirmed runaway worker gracefully, and prove it has exited.

What you will practise

  1. Assess the starting state — CPU-intensive processes ranked. 20 pts
  2. Locate and stop the runaway process — Produce the required modeled system state using supported administrative commands. 60 pts
  3. Validate the resulting state — Runaway process exit validated. 20 pts

Commands used in this lab

  • ps -eo pid,user,pcpu,pmem,comm --sort=-pcpu | head
  • kill -TERM 4242
  • sleep 2
  • ! ps -p 4242
