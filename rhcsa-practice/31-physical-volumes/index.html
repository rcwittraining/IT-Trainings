Prepare the approved partition as a new LVM physical volume and retire an unused unassigned physical volume.

What you will practise

  1. Assess the starting state — Physical volume inventory inspected. 20 pts
  2. Create and remove physical volumes — Produce the required modeled system state using supported administrative commands. 60 pts
  3. Validate the resulting state — Physical volume state validated. 20 pts

Commands used in this lab

  • pvs -o pv_name,vg_name,pv_size
  • pvcreate /dev/vdb1
  • pvremove -y /dev/vdc1
