Non-destructive Storage and Swap

Add a 1 GiB swap logical volume to the running system without disturbing existing data and make it persistent.

Task 35 of 62 in the RHCSA practice series. Mapped to the published EX200 skill areas.

  • RHCSA / EX200level
  • 3objectives
  • 10 mintarget time
  • 100points + certificate

Start the interactive lab ↓ Free · runs in your browser · no login

What you will practise

  1. Assess the starting state — Volume-group free space inspected. 20 pts
  2. Add persistent swap non-destructively — Produce the required modeled system state using supported administrative commands. 60 pts
  3. Validate the resulting state — Active swap validated. 20 pts

Commands used in this lab

  • vgs vgsystem -o vg_name,vg_free
  • lvcreate -L 1G -n lvswap vgsystem
  • mkswap /dev/vgsystem/lvswap
  • swapon /dev/vgsystem/lvswap
  • printf '/dev/vgsystem/lvswap none swap defaults 0 0\n' >> /etc/fstab
  • swapon --show | grep lvswap
