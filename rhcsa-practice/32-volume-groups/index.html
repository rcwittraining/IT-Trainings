Create the application volume group from the first approved PV, then add the second PV to expand its capacity.

What you will practise

  2. Create and extend the volume group — Produce the required modeled system state using supported administrative commands. 60 pts
  3. Validate the resulting state — Volume group membership validated. 20 pts
