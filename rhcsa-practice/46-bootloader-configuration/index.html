Add persistent auditing to every installed kernel command line and confirm the setting across boot entries.

What you will practise

  1. Assess the starting state — Default kernel identified. 20 pts
  2. Modify persistent bootloader kernel arguments — Produce the required modeled system state using supported administrative commands. 60 pts
  3. Validate the resulting state — Bootloader arguments validated. 20 pts

Commands used in this lab

  • grubby --default-kernel
  • grubby --update-kernel=ALL --args='audit=1'
  • grubby --info=ALL | grep -E '^args=.*audit=1'
