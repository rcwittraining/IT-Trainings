Network Service Autostart

Ensure the management connection and NetworkManager service recover automatically after boot.

Task 49 of 62 in the RHCSA practice series. Mapped to the published EX200 skill areas.

  • RHCSA / EX200level
  • 3objectives
  • 10 mintarget time
  • 100points + certificate

Start the interactive lab ↓ Free · runs in your browser · no login

What you will practise

  1. Assess the starting state — Management connection inspected. 20 pts
  2. Enable persistent network startup — Produce the required modeled system state using supported administrative commands. 60 pts
  3. Validate the resulting state — Connection and boot service state validated. 20 pts

Commands used in this lab

  • nmcli connection show Management
  • nmcli connection modify Management connection.autoconnect yes
  • systemctl enable --now NetworkManager
  • nmcli -f GENERAL.STATE,GENERAL.CONNECTION device show ens224 && systemctl is-enabled NetworkManager
