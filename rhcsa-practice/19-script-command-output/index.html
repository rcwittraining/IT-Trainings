What you will practise

  1. Assess the starting state — Source command output inspected. 20 pts
  2. Process command output inside a script — Produce the required modeled system state using supported administrative commands. 60 pts
  3. Validate the resulting state — Captured command output validated. 20 pts

Commands used in this lab

  • hostname -f
  • chmod 0755 /usr/local/bin/host-snapshot
  • bash -n /usr/local/bin/host-snapshot
  • /usr/local/bin/host-snapshot && grep -E '^(host|time|uptime)=' /var/tmp/host.snapshot
