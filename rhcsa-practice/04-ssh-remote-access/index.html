Secure Shell Remote Access

Connect from the administration host to serverb using the assigned key and verify the remote identity without enabling password authentication.

Task 4 of 62 in the RHCSA practice series. Mapped to the published EX200 skill areas.

  • RHCSA / EX200level

Start the interactive lab ↓ Free · runs in your browser · no login

What you will practise

  1. Assess the starting state — Assigned public key fingerprint inspected. 20 pts
  2. Establish key-based remote shell access — Produce the required modeled system state using supported administrative commands. 60 pts
  3. Validate the resulting state — Remote identity validated. 20 pts

Commands used in this lab

  • ssh-keygen -lf /home/admin/.ssh/id_ed25519.pub
  • ssh -i /home/admin/.ssh/id_ed25519 opsadmin@serverb.lab 'hostname'
  • ssh -i /home/admin/.ssh/id_ed25519 opsadmin@serverb.lab 'id -u'
