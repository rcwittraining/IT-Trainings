Need a hint?Open link guide

Inspect: ls -li /data/db/orders.db or stat /data/db/orders.db.

Hard link: ln /data/db/orders.db /backup/orders.db (no -s).

Verify: ls -li /data/db/orders.db /backup/orders.db — same inode, link count 2.

Prove: echo 'update' >> /data/db/orders.db then cat /backup/orders.db.
