What you will practise

  1. View inventory — Read the inventory file. 25 pts

  3. Ping — Ping with ansible all -m ping. 25 pts

Commands used in this lab

  • cat /etc/ansible/hosts

  • ansible all -m ping
  • ansible webservers -m command -a 'uptime'
