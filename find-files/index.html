find File Search

Locate files and directories with the find command using name, type, and size filters.

What you will practise

  1. Find by name — Find files named report.txt. 25 pts
  2. Find by type — Find directories with -type d. 25 pts
  3. Find by size — Find files larger than 1M with -size +1M. 25 pts
  4. Find and act — Combine find with -exec. 25 pts

Commands used in this lab

  • find /data -name report.txt
  • find /data -type d
  • find / -size +1M
  • find /data -name '*.txt' -exec ls -l {} ;
