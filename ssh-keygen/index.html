SSH Key Setup

Generate and manage SSH key pairs for passwordless authentication.

  • Beginnerlevel
  • 3objectives
  • 10 mintarget time

Start the interactive lab ↓ Free · runs in your browser · no login

What you will practise

  1. Generate key — Generate an ed25519 key with ssh-keygen. 34 pts
  2. Copy public key — Copy the key with ssh-copy-id. 33 pts
  3. Check fingerprint — Show the fingerprint with ssh-keygen -l. 33 pts

Commands used in this lab

  • ssh-keygen -t ed25519
  • ssh-copy-id user@host
  • ssh-keygen -lf ~/.ssh/id_ed25519.pub
