File Permissions (chmod)

Understand and modify file permissions with chmod (symbolic and numeric).

  • Beginnerlevel
  • 4objectives
  • 10 mintarget time
  • 100points + certificate

Start the interactive lab ↓ Free · runs in your browser · no login

What you will practise

  1. Make executable — Make script.sh executable with chmod +x. 25 pts
  2. Numeric mode — Set report.txt to 644 with numeric mode. 25 pts
  3. Read-only — Remove write with chmod -w. 25 pts
  4. Recursive — Apply recursively with -R. 25 pts

Commands used in this lab

  • chmod +x /data/script.sh
  • chmod 644 /data/report.txt
  • chmod -w /data/report.txt
  • chmod -R 755 /data
