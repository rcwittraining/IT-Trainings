How this works & security notes
  1. Approve chooses the tool and (optionally) records the requester; the console generates a unique code and writes it to your private-ish code list automatically.
  2. Send the code using the ready-made e-mail button. The requester pastes it on the tool page and the download unlocks.
  3. Revoke removes the code with one click; it stops working within ~5 minutes.
  4. Your GitHub token is stored only in this browser (localStorage), never in the website files. Clear it anytime with the button below. Use this console only on your own device.
  5. This gate unlocks downloads on a public GitHub Pages host — it is an approval/access layer, not server-side security. For tools that must never be publicly reachable, keep them in the private repository flow.
