2 · How to activate (one minute)

  1. Click Generate access code above.
  2. Click Copy hash line, then Open code list (the GitHub note). Sign in as rcwittraining if asked.
  3. In the note, click the Edit (pencil) button, paste the line under the existing codes, then Update public gist.
  4. Click Copy approval e-mail and send it (add the requester's address) — it contains their code and the download page link.
  5. To revoke: delete that line from the note and save. The code stops working within ~5 minutes.
Security note: this unlocks the download buttons on a GitHub Pages site. The files in /downloads/ are on a public host and the gate is an obfuscation/access layer, not true server-side security. For tools that must not be publicly reachable at all, keep the installers in your private GitHub repository and share them privately (as described on the admin area). This issuer is ideal for the “approve, then give a personal code” flow for your public-page tools.
