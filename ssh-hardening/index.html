SSH Server Hardening

Harden the SSH daemon by editing sshd_config settings.

  • Intermediatelevel
  • 4objectives
  • 10 mintarget time
  • 100points + certificate

Start the interactive lab ↓ Free · runs in your browser · no login

What you will practise

  1. Disable root login — Set PermitRootLogin no. 25 pts
  2. Change port — Set Port 2222. 25 pts
  3. Disable password auth — Set PasswordAuthentication no. 25 pts
  4. Reload sshd — Restart sshd with systemctl. 25 pts

Commands used in this lab

  • sed -i 's/PermitRootLogin yes/PermitRootLogin no/' /etc/ssh/sshd_config
  • sed -i 's/#Port 22/Port 2222/' /etc/ssh/sshd_config
  • systemctl restart sshd

Files present on the lab host

  • /etc/ssh/sshd_config
    # $OpenBSD: sshd_config
Port 22
PermitRootLogin yes
PasswordAuthentication yes
X11Forwarding yes
