What you will practise

  1. Create user — Create with CREATE USER. 34 pts
  2. Grant privileges — Grant with GRANT ALL. 33 pts
  3. Flush privileges — Apply with FLUSH PRIVILEGES. 33 pts

Commands used in this lab

  • CREATE USER 'app'@'localhost' IDENTIFIED BY 'password';
  • GRANT ALL ON app.* TO 'app'@'localhost';
  • FLUSH PRIVILEGES;
