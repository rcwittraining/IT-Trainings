Need a hint?Open link guide

List with links: ls -l /usr/local/bin/rcw-app or ls -l /usr/local/bin.

Resolve a link: readlink /usr/local/bin/rcw-app or readlink -f ….

Remove only the link: rm /usr/local/bin/rcw-app or unlink /usr/local/bin/rcw-app.

Create a soft link: ln -s /opt/rcw-app/v2.1/rcw-app /usr/local/bin/rcw-app.

Config link: ln -s /opt/rcw-app/v2.1/config.ini /etc/rcw-app/config.ini.

Type help to see all supported commands.
