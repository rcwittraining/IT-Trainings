Embedded dashboard

📊
Your embedded dashboard is one free 5-minute setup away.

Create a free Looker Studio report from your Google Analytics data, enable embedding, and paste the embed link to RCW IT Training. Steps are below.

  1. Go to lookerstudio.google.com and sign in with the same Google account used for Analytics.
  2. Create → Report, then in “Add data to report” choose the Google Analytics connector and select the rcwittraining.in property / web stream.
  3. Add a few charts (menu Add a chart): a scorecard for Users, a time series of Users by date (daily traffic), a table of Page paths by Views, and optionally device/country breakdowns.
  4. Share (top right) → set link access to “Anyone on the internet with the link can view”.
  5. File → Embed report → tick Enable embedding → copy the embed URL (it starts with https://lookerstudio.google.com/embed/reporting/).
  6. Send that link to RCW IT Training to finish wiring this page, or paste it into the <iframe src=""> in dashboard.html.

Tip: set the report date control to “Last 30 days” so the dashboard always shows current daily traffic.
