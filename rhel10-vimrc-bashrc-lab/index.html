Complete each objective in the simulated system. Command text alone is not enough—the resulting files and shell state are checked.

Inspect both dotfiles

10 pts

Read the current .vimrc and .bashrc.

cat ~/.vimrc

2

Protect the originals

15 pts

Create .bak copies before editing.

cp -p ~/.vimrc ~/.vimrc.bak
cp -p ~/.bashrc ~/.bashrc.bak
✓
3

Configure Vim defaults

25 pts

Enable numbers, syntax, spaces, four-column widths and auto-indent.

vim ~/.vimrc
Add: set number, syntax on, set expandtab, set tabstop=4, set shiftwidth=4, set autoindent.
✓
4

Configure Bash

25 pts

Set the editor, history controls and two practical aliases.

vim ~/.bashrc
Add exports for EDITOR, VISUAL, HISTCONTROL, HISTSIZE plus aliases ll and c.
✓
5

Reload and verify

15 pts

Source the file, then prove the editor, history and alias are active.

source ~/.bashrc
echo $EDITOR
echo $HISTSIZE
type ll
✓
6

Validate and review

10 pts

Run a Bash syntax check and review changes against both backups.

bash -n ~/.bashrc
diff -u ~/.vimrc.bak ~/.vimrc
diff -u ~/.bashrc.bak ~/.bashrc
