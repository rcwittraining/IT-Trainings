Need a hint?Open setup guide

Install tools with sudo apt-get install -y kubelet kubeadm kubectl.

Initialise with sudo kubeadm init --pod-network-cidr=10.244.0.0/16.

Configure kubectl: mkdir -p $HOME/.kube, then sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config, then sudo chown $(id -u):$(id -g) $HOME/.kube/config.

Apply the CNI: kubectl apply -f https://raw.githubusercontent.com/flannel-io/flannel/master/Documentation/kube-flannel.yml.

Verify with kubectl get nodes.

Type help to see all supported commands.
