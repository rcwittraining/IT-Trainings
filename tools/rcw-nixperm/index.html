Supported operations

  • chown — change owner
  • chgrp — change group
  • chmod — numeric (0755) or symbolic (u+rwx)
  • u+s / u-s — set/remove SUID bit
  • g+s / g-s — set/remove SGID bit
  • o+t / o-t — set/remove sticky bit
  • setfacl — POSIX ACL entries (u:user:rwx, g:group:rx)

How it works

  1. Install nothing — copy the exe to any Windows 10/11 machine and double-click. The target server just needs SSH and a sudo-capable user (or root).
  2. Connect: enter the host, port, username and password (or SSH key). Optionally provide a sudo password for privileged operations.
  3. Audit: enter any path (e.g. /var/www, /home, /etc), check Recursive for full tree scan, check Include ACL to pull POSIX ACLs with getfacl.
  4. Export: save the full audit to an Excel workbook with a Permission Audit sheet (every file with highlighted world-writable items and special bits) and a Summary sheet (counts of SUID files, SGID items, world-writable dirs without sticky bit, etc.).
  5. Modify: select a file or folder in the table, enter the desired changes (chown, chgrp, chmod, ACL), use the quick-buttons for u+s, g+s, o+t and their removal, then click Apply. Dry-run is on by default — preview every command before it runs.
Safety: RCW-NixPerm defaults to dry-run mode. Every change is shown as a command preview before execution. Recursive operations are flagged explicitly. Always test permission changes on non-production systems first.

What it manages

Standard permissions

  • ✓Read / Write / Execute for owner, group, other
  • ✓Numeric mode (0644, 0755, 4755, 2775…)
  • ✓Symbolic mode (u+rwx, g-w, o=rx…)
  • ✓Owner and group changes

Special bits & ACLs

  • ✓SUID bit (u+s) — execute as owner
  • ✓SGID bit (g+s) — execute as group / inherit group
  • ✓Sticky bit (o+t) — restrict deletion in shared dirs
  • ✓POSIX ACL (setfacl) — per-user/group access
