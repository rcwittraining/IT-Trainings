    Connector tips

    • Hover a shape → drag from a blue port dot to another shape. Drop on a specific port to pin that side, or anywhere on the shape for auto-routing.
    • Drag a connector's end from the empty canvas to auto-create a linked copy of the source shape (fast for access-switch fan-outs).
    • Select a connector → drag the centre dot to add a waypoint; use "Reset waypoints" to return to automatic routing.
    • For LLD, fill in Source end / Target end labels (Gi1/0/1 ↔ Gi1/0/48) and choose the media type so the legend stays accurate.

    About RCW - NetArchitect

    A free, browser-based studio for High-Level Design (HLD) and Low-Level Design (LLD) diagrams - network topologies, security zones, hybrid-cloud connectivity, rack elevations and software architecture (C4-style). Built by RCW IT Training.

    Privacy & data

    • Nothing you draw is uploaded. Rendering, export and checks run entirely in your browser; there is no back-end and no account.
    • Your work is auto-saved to this browser's local storage only, so you can continue later on the same device. Use Save (JSON) to keep a portable copy or move between devices.
    • Opened files are strictly validated (typed schema, size limits, escaped text) before rendering.
    • The site's cookie / analytics choices apply as described in the privacy policy; the editor itself sets no additional cookies.

    Standards & conventions

    • Library (v1.1): 269 shapes in 13 categories - basic geometry, lines & markers, network, security, compute, end-points, cloud, software/C4, UML & ERD/BPMN, zones, LLD items, full flowchart set, annotations - plus 30 connector types and 13 arrow-head styles. Use the search box or "Jump to category" in the Shapes panel.
    • Notation: vendor-neutral symbol set following common industry conventions (router = circle with arrows, switch = box with arrows, firewall = brick wall, zones as dashed regions). Cloud stencils are generic so one diagram can describe AWS, Azure or GCP. Cisco, AWS, Microsoft, Google, VMware and others are trademarks of their respective owners; this tool is not affiliated with them.
    • Documentation: title block (title, version, author, date, status, classification), legend, revision history and detail tables follow typical enterprise design-document (HLD/LLD) practice.
    • Software architecture: C4 model person / system / container / component conventions.
    • Accessibility: designed to WCAG 2.1 AA - full keyboard operation, visible focus, screen-reader announcements, colour-contrast checks on your diagram, and exported SVGs carry <title>/<desc> metadata.
    • Interchange: open JSON format, SVG 1.1 with Dublin Core metadata, PNG/JPEG, PDF via the browser print engine, CSV inventory & connection schedules.
